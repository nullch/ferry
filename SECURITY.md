# Политика безопасности

Инструмент работает от root и переносит секреты (хэши паролей, ключи), поэтому о проблемах просим сообщать приватно:
**GitHub → Security → Report a vulnerability** (не создавайте публичный issue).

Мы отвечаем в течение нескольких дней. Поддерживается последняя минорная версия.

Рекомендации: храните `ca.key` офлайн, запускайте `ferry serve` только на время переноса, ограничьте порт файрволом, удаляйте `/var/lib/ferry/sessions/*` после миграции.

Если GitHub-форма недоступна — напишите автору в Telegram: [@nullch](https://t.me/nullch) (без технических деталей в открытых чатах).
