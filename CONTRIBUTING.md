# Участие в разработке

1. `make vet test build` должны проходить (Go ≥ 1.19, **без внешних зависимостей** — только stdlib).
2. Новый дистрибутив/пакетный менеджер: реализуйте интерфейс `PkgMgr` в `cmd/ferry/pkgmgr.go` и добавьте семейство в `detectFamily`/`detectPM` (`distro.go`).
3. Соответствия пакетов — строки таблицы в `cmd/ferry/pkgmap.go` (формат `debian | rhel | suse | arch | alpine`).
4. Тесты — `cmd/ferry/ferry_test.go`; чистые функции (парсеры, сопоставления) обязательно с тестами.
5. Всё, что трогает систему (apply), должно быть идемпотентным и сохранять бэкап перезаписанного.
6. Коммиты: короткое повелительное сообщение; PR — с описанием, на каких дистрибутивах проверено.
